# v1.6.0 — пакетный импорт и окно выбора режима

- Вернул окно выбора Classic / Color Kingdoms после нажатия «Запустить».
- Удалил предварительный переключатель режима из панели библиотеки; карточка теста показывает «Режим выбирается при запуске».
- Импорт поддерживает множественный выбор файлов XLSX/XLS/JSON и объединяет их в один серверный запрос.
- В открытой папке действие «Создать тест» заменено на «Импортировать тесты»; импортируемые таблицы назначаются выбранной папке.
- В пакетном импорте JSON папки из разных источников получают уникальные ID и имена. При импорте в папку структура исходных папок не дублируется.
- Диалог выбора режима переведён на RU/EN/中文, закрывается через Escape/кнопку отмены, блокирует повторное нажатие во время создания комнаты и возвращает фокус на карточку теста при отмене.
