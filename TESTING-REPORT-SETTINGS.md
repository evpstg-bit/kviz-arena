## Ограничения

- GitHub Contents API не проверялся на реальном токене пользователя; для этого на Render необходимо настроить `GITHUB_TOKEN`, `GITHUB_REPOSITORY`, `GITHUB_BRANCH` с правом Contents: Read and write.
- Полный визуальный прогон взаимодействия в реальном браузере не выполнялся. Проверены синтаксис и серверные интеграционные сценарии.
- Render Free не гарантирует сохранность локальных файлов при новом развёртывании. Для постоянных настроек используйте GitHub-синхронизацию или персистентное хранилище.
