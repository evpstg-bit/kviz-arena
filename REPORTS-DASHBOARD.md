# Отчёты о прохождении тестов

## В интерфейсе

- Кнопка **Отчёты** доступна в кабинете преподавателя.
- Отчёты группируются по тесту, каждый запуск сохраняется отдельной сессией.
- После завершения Classic или Color Kingdoms ведущий автоматически попадает в отчёт текущей сессии.
- Подробный отчёт включает вкладки `Summary`, `Participants`, `Questions`; вкладка участников содержит под-вкладки `All`, `Needs help`, `Teams`.
- Отчёт можно выгрузить в XLSX (листы Summary, Participants, Questions, Teams).

## Данные и вычисления

- В статистику включаются ответы из журнала каждого игрока; участники, которые вышли или были исключены, сохраняются в снимке отчёта.
- На уровне вопроса считаются попытки, верные и неверные ответы, точность, количество ответивших и количество выборов каждого варианта.
- «Нуждаются в помощи» означает точность ниже 60% либо отсутствие ответов.
- Для Classic считаются пропуски. Для Color Kingdoms считаются флаги, клетки и командные показатели.
- При завершении ведущим до окончания теста отчёт помечается как досрочный и содержит только фактически собранные ответы.
- API отчётов требует авторизации; преподаватель видит собственные отчёты, администратор — все.

## Хранение

Сервер записывает отчёты в ``DATA_DIR`/reports.json`; каталог по умолчанию — `data`. Не коммитьте реальные отчёты в репозиторий, поскольку они содержат данные студентов. На Render Free файловая система не постоянна. Для долговременной истории задайте `DATA_DIR` внутри persistent disk или используйте внешнюю БД.
