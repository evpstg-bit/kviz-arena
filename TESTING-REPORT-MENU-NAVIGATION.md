# Проверка меню и навигации — версия 1.8.0

## Успешные проверки

- `node --check server.js` — без синтаксических ошибок.
- JavaScript из `public/index.html` — без синтаксических ошибок.
- `postcss.parse` для `public/liquid-glass.css`, `public/ui.css` и `public/tailwind.css` — без ошибок.
- JSON-проверка `builtin-tests.json` и `app-settings.json` — успешно.
- Локальные HTTP smoke-проверки: `/` возвращает HTTP 200, `/api/info` возвращает HTTP 200, `/liquid-glass.css?v=9` возвращает HTTP 200.
- Unit-проверка логики навигационной истории: home → auth → lib → конкретная папка; переход назад и вперёд сохраняет позицию, не создаёт дубликатов и восстанавливает нужную папку.
- Проверка HTML helper для меню: для администратора генерируются пункты «Библиотека», «Отчёты», «Настройки», «Экспорт библиотеки», «Импорт файлов», «На главную», «Выйти»; в шапке есть кнопка меню и кликабельный бренд.
- CSS меню использует скрытие через `visibility/opacity/pointer-events` и раскрытие при `:hover`, `:focus-within` или открытом состоянии для сенсорных экранов.

## Ограничение

Полный браузерный визуальный прогон не завершён: браузерная тестовая среда блокирует доступ к локальному адресу приложения. Поэтому итоговая проверка меню на реальном экране после развёртывания рекомендуется.
