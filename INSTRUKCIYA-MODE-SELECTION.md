# Выбор режима при запуске теста

1. Импортируйте XLSX обычным способом в кабинете преподавателя.
2. В библиотеке у импортированного теста будет подпись «Режим выбирается при запуске» — импорт не закрепляет Classic или Color Kingdoms.
3. Нажмите «Запустить». Откроется окно с описанием двух режимов.
4. Выберите Classic для стандартной викторины или Color Kingdoms для командной игры с захватом территории.
5. Только после выбора создаётся игровая комната и показывается PIN-код участникам.

Режим выбирается отдельно при каждом запуске и не переписывает тест или правильные ответы. Для каждого запуска можно выбрать другой режим. Окно режима переведено на русский, английский и китайский; закрывается кнопкой «Отмена», крестиком, щелчком по затемнённому фону или клавишей Escape.

## Развёртывание

Загрузите содержимое архива в корень репозитория и выполните Commit & Push. Render должен развернуть обновлённые `server.js`, `public/index.html` и `public/liquid-glass.css` вместе.
