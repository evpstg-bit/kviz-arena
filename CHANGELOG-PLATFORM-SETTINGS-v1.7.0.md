# v1.7.0 — Глобальные настройки платформы

Добавлена страница «Настройки» в корневую навигацию кабинета администратора.

## Игровые режимы

- Включение и отключение Classic и Color Kingdoms на уровне платформы.
- Базовые баллы за правильный ответ и бонус скорости для Classic.
- Длительность Color Kingdoms и число правильных ответов, необходимых для получения флага.
- Нельзя отключить оба режима одновременно.

## Общие настройки

- Время по умолчанию для новых тестов и вопросов.
- Максимальное количество участников в комнате.
- Порог точности для отчётной категории «Нуждаются в помощи».
- Автоматическое открытие отчёта после игры.
- Показ правильных ответов после завершения вопроса.

## Хранение

- Настройки нормализуются и ограничиваются допустимыми диапазонами на сервере.
- Сохраняются в `app-settings.json`.
- При наличии `GITHUB_TOKEN`, `GITHUB_REPOSITORY` и `GITHUB_BRANCH` синхронизируются с GitHub Contents API в том же репозитории, что и библиотека тестов.
- Без GitHub-синхронизации UI скачивает резервный `app-settings.json` и предупреждает о непостоянном хранилище Render.
- Каждая новая игровая сессия получает снимок настроек, поэтому изменение параметров не меняет уже запущенные игры.
