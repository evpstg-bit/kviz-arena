# Navigation menu hover and contrast fix

- Added a hover bridge between the hamburger trigger and the floating menu so the dropdown does not disappear while moving the pointer into it.
- Added a short delayed close that checks whether the pointer is truly outside the wrapper. Touch/click toggle behavior remains supported.
- Increased panel opacity in the light theme and added a more opaque, high-contrast surface in the dark theme.
- Bumped the Liquid Glass CSS query version to avoid stale browser cache.
