# Отчёты: порог сложных вопросов 40%

В подразделе «Где возникли трудности» показываются только вопросы, на которые правильно ответили менее 40% всей группы участников.

- Знаменатель — все участники отчёта, включая тех, кто не ответил на конкретный вопрос.
- Для точности ниже порога вопрос попадает в список; ровно 40% не попадает.
- Отображается процент по всей группе, а не только среди ответивших. Дробные значения показываются с одним знаком после запятой, когда это необходимо, чтобы не округлять 39,5% до 40%.
- Старые отчёты без нового поля совместимы: показатель рассчитывается на лету из количества правильных ответов и количества участников.
- Пустое состояние сообщает, что вопросов с точностью ниже 40% не найдено.
- Добавлены подписи для английского и китайского интерфейса.
