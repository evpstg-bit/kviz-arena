# Исправление запуска после выбора режима

- Исправлен переход интерфейса: после успешного создания игровой комнаты экран ведущего переводится в состояние `game` до подключения Server-Sent Events. Ранее оставался `view='lib'`, а обработчик событий намеренно не переключал библиотеку на игру; из-за этого ведущий видел библиотеку до перезагрузки страницы.
- Окно выбора режима остаётся видимым и блокирует повторные нажатия, пока сервер создаёт комнату.
- Добавлен статус загрузки и переводы на русский, английский и китайский языки.
- Ошибки запроса создания комнаты теперь возвращают пользователя в библиотеку с сообщением, вместо зависшего или скрытого окна.
- Проверен ответ API создания комнаты и наличие PIN/ID перед подключением.
