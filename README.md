# Квиз-арена


## Вход администратора и сохранение тестов на Render

Для входа администратора проект использует файл `admin-credentials.json` в корне репозитория. В текущем архиве настроены логин `bntu` и пароль `230825`. Учётная запись создаётся сервером автоматически при каждом запуске, а подписанная сессия администратора действует до 60 дней и не пропадает при обычном перезапуске Render.

**Важно:** файл содержит пароль в открытом виде. Если GitHub-репозиторий публичный, любой пользователь сможет его увидеть и войти в кабинет. Перед публикацией проекта лучше сделать репозиторий приватным или заменить механизм на секрет Render Environment Variables.

Тесты, которые должны переживать перезапуски бесплатного Render, храните в `builtin-tests.json` или `saved-tests.json` в корне проекта. Файлы входят в репозиторий: после изменения сделайте commit/push и дождитесь деплоя. Личная библиотека `Мои тесты` всё ещё хранится в `DATA_DIR`; на бесплатном Render эта файловая система временная. Чтобы сохранить экспортированные тесты надолго, скопируйте содержимое `moi-testy.json` в поле `items` файла `saved-tests.json` и отправьте изменения в GitHub.


Платформа для проведения викторин в классе: преподаватель создаёт тесты в личном кабинете и запускает игру
на большом экране, студенты подключаются со своих устройств (по QR-коду или PIN) и отвечают.

**Подробная инструкция по настройке личного кабинета, встроенным тестам и серверу — в файле `INSTRUKCIYA.md`.**

## Быстрый старт
Нужен только Node.js 18+ (https://nodejs.org), зависимости ставить не нужно.

    node server.js

Откройте http://localhost:3000 → «Войти / Регистрация» → войдите логином `bntu`, паролем `230825` (данные задаются в `admin-credentials.json`).
Студенты открывают адрес из строки «В локальной сети» или сканируют QR-код в лобби.

## Режимы игры
- **Classic** — вопросы идут по очереди для всех; очки за правильность и скорость; несколько правильных ответов
  (нужно выбрать все); свой таймер у каждого вопроса.
- **Color Kingdoms** — две команды (красные и синие), игроки делятся случайно. Каждый отвечает в своём темпе:
  за заданное число верных ответов игрок ставит флаг на карту рядом с территорией своей команды. Окружённые
  территории переходят к окружившей команде; если окружена ладья ♜ соперника — команда получает трофей и
  начинается новый раунд. Когда время игры (1–10 мин) выходит, команда с бо́льшим числом клеток берёт трофей;
  побеждает команда с бо́льшим числом трофеев. Вопросы повторяются по кругу.

## Возможности
- Личный кабинет: аккаунты, личная библиотека тестов (сохранение, изменение, дублирование, удаление),
  вход с любого компьютера, экспорт/импорт тестов в файл.
- Импорт вопросов из Excel (.xlsx): шаблон — в редакторе, пример — `examples/primer-voprosov.xlsx`.
- Встроенные и закреплённые в проекте тесты из `builtin-tests.json` и `saved-tests.json`: они входят в деплой и остаются доступными после перезапуска Render.
- До 100 игроков, вход по QR-коду / PIN, в том числе после начала игры; исключение игроков; закрытие входа;
  выгрузка результатов в Excel.

## Настройки (переменные окружения)
| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | порт сервера | `3000` |
| `DATA_DIR` | папка с аккаунтами и тестами | `./data` |
| `INVITE_CODE` | код приглашения для регистрации новых преподавателей | пусто (после первого аккаунта регистрация закрыта) |

Пример: `INVITE_CODE=секрет DATA_DIR=/var/lib/kviz PORT=8080 node server.js`

Команда `node server.js --users` показывает логины. Для смены пароля администратора `bntu` отредактируйте `admin-credentials.json` и повторно разверните проект; пароль других аккаунтов можно изменить командой `node server.js --reset-password ЛОГИН НОВЫЙ_ПАРОЛЬ`.

## Оформление (Tailwind CSS)
Стили собраны заранее в `public/tailwind.css` — для запуска ничего устанавливать не нужно.
Если меняете классы в `public/index.html` или `src/input.css`: `npm install && npm run build:css`.
