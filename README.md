# Квиз-арена

Платформа для проведения викторин в классе: преподаватель создаёт тест и запускает игру на большом экране,
студенты подключаются со своих устройств и отвечают на вопросы. Очки, рейтинг и итоги — в реальном времени.

## Запуск
Нужен только Node.js 16+ (https://nodejs.org). Зависимости ставить не нужно.

    node server.js

Преподаватель открывает http://localhost:3000, студенты — адрес из строки «В локальной сети»
(или сканируют QR-код в лобби). Порт: `PORT=8080 node server.js`.

## Возможности
- Два режима: **Classic** (каждый сам за себя, очки за верность и скорость) и **Color Kingdoms**
  (студенты делятся на 2–4 цветных королевства и захватывают клетки карты).
- Вопросы с несколькими правильными ответами, своё время на каждый вопрос.
- Импорт вопросов из Excel (.xlsx): кнопка «Скачать шаблон» в редакторе, пример — `examples/primer-voprosov.xlsx`.
- **Библиотека тестов**: сохранение, изменение, дублирование и удаление; запуск игры в один клик.
- До 100 игроков, вход по QR-коду / PIN, в том числе после начала игры; исключение игроков;
  выгрузка результатов в Excel.

## Библиотека тестов
Тесты хранятся на сервере в файле `data/quizzes.json` (папку можно задать: `DATA_DIR=/путь node server.js`).
Резервная копия — просто скопируйте этот файл.

Доступ к библиотеке защищён, чтобы студенты не увидели правильные ответы:
- без пароля она открывается только на компьютере, где запущен сервер (`localhost` или его адрес в сети);
- для удалённого сервера задайте пароль: `TEACHER_PASSWORD=секрет node server.js` — он понадобится
  для библиотеки и для создания игр.

На бесплатных хостингах с временной файловой системой (например, на бесплатном тарифе Render)
файл `data/` может сбрасываться при перезапуске — используйте постоянный диск или свой сервер.

## Оформление (Tailwind CSS)
Стили собраны заранее в `public/tailwind.css` — для запуска ничего устанавливать не нужно.
Если меняете классы в `public/index.html` или `src/input.css`: `npm install && npm run build:css`.
