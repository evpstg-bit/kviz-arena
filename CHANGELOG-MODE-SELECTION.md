# Изменение: выбор режима перед запуском

- XLSX-импорт больше не присваивает режим `Classic`: импортированные тесты получают нейтральное значение `choose`.
- После нажатия «Запустить» открывается отдельный диалог выбора `Classic` или `Color Kingdoms`; комната создаётся только после явного выбора.
- Выбор режима отправляется в серверный API и используется для текущей игровой комнаты. Он не меняет сам тест и не закрепляется за ним.
- В библиотеке тестов карточки показывают, что режим определяется при запуске; убраны фильтры, которые подразумевали закреплённый за тестом режим.
- В редакторе вместо фиксированного режима показано пояснение; настройки длительности и флагов Color Kingdoms сохранены.
- Диалог доступен на русском, английском и китайском, поддерживает Escape и отображение для мобильных экранов.
