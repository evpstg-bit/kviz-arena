# Исправление импорта файлов в папку — v1.10.8

- Исправлена кнопка «Импортировать тесты» внутри созданной папки: она ссылалась на отсутствующий элемент `#impf`, поэтому диалог выбора файлов не открывался.
- Кнопка теперь использует общий обработчик импорта кабинета преподавателя и открывает существующий файловый диалог.
- Сохранён выбор нескольких файлов за один раз: input имеет атрибут `multiple`, а обработчик последовательно читает XLSX/XLS/JSON и направляет импортированные тесты в открытую папку.
- Обновлены версии CSS в URL для сброса кэша браузера.

Проверки: синтаксис `server.js`, встроенного JavaScript, JSON-файлов и целостность архива. Реальный браузерный тест с выбором файлов вручную не выполнялся в этой среде.
