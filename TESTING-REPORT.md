# Отчёт о проверке платформы

Проверена сборка 1.4.0 с корневой навигацией кабинета преподавателя и папками предметов.

## Автоматические проверки

- Синтаксис `server.js` и основного встроенного клиентского JavaScript — пройден.
- JSON-файл `builtin-tests.json` — корректно разбирается; исходная схема версии 2 успешно читается.
- CSS `public/liquid-glass.css` — парсер CSS не обнаружил синтаксических ошибок.
- Статическая HTML-структура и наличие корневой навигации/контролов папок — проверены.
- Ответы HTTP 200 проверены для главной страницы, Tailwind CSS, базового UI CSS, Liquid Glass CSS, XLSX и QR библиотек.

## Интеграционные проверки API

Пройдены 51 сценарий, включая:

- вход преподавателя и защиту API папок;
- создание папок и запрет дублирующихся названий;
- импорт теста в выбранную папку, перемещение между папкой и корнем;
- копирование и редактирование теста с сохранением назначения папки;
- переименование папки и проверку конфликтов названий;
- JSON-экспорт версии 3 и импорт папок вместе с тестами;
- повторное использование папки по имени при JSON-импорте;
- удаление папки без удаления тестов — тесты остаются в разделе «Без папки»;
- запуск Classic и получение вопроса участником через SSE;
- ответы, переход к следующему вопросу, завершение игры и запись отчёта;
- запуск Color Kingdoms и получение игрового состояния участником.

## Ограничения

Полный визуальный прогон в Chromium не завершился: тестовая среда блокирует навигацию браузера к локальному серверу с ошибкой `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому подтверждены синтаксис, структура и серверные интеграционные сценарии, но не утверждается, что выполнен полный ручной визуальный просмотр всех экранов.

Синхронизация с реальным GitHub-репозиторием не запускалась, поскольку для неё нужны личные секреты `GITHUB_TOKEN`, `GITHUB_REPOSITORY` и `GITHUB_BRANCH` из окружения пользователя. Код синхронизации сохранён и продолжает использовать тот же файл `builtin-tests.json`.
