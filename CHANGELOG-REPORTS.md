# Отчёты после прохождения теста

- Добавлена страница истории отчётов в кабинете преподавателя; история группируется по тесту и показывает отдельные прохождения.
- После завершения игры ведущему автоматически открывается отчёт текущего запуска.
- Добавлены разделы «Общая статистика», «Участники» и «Вопросы»; в статистике участников доступны «Все участники», «Нуждаются в помощи» и «Статистика по командам».
- Добавлены показатели правильных/неправильных ответов, точности, индивидуальных очков, пропусков и выбора ответов по вопросу.
- Добавлен экспорт XLSX с листами Summary, Participants, Questions и Teams.
- История хранится в `DATA_DIR/reports.json`; API ограничивает доступ владельцем отчёта и администратором.
- Отчёты не отправляются в GitHub автоматически, чтобы не публиковать индивидуальные результаты студентов.
