# Квиз-арена v1.10.4 — исправлен большой верхний отступ на мобильных устройствах

- На узких портретных экранах верхний отступ приложения уменьшен до 6 CSS-пикселей.
- Для шапки явно сброшен дополнительный верхний отступ.
- Обновлены версии CSS-ресурсов в HTML, чтобы браузеры не использовали закэшированные старые стили.
- Правило не отменяет зарезервированное пространство для плавающего меню на игровых экранах без шапки.
- Игровая логика, тесты и данные проекта не изменялись.
