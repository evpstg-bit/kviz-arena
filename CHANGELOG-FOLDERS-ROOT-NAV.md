# Папки предметов и корневая навигация

- Добавлена корневая навигация кабинета преподавателя: «Библиотека» и «Отчёты» доступны из рабочих экранов и редактора.
- Библиотека получила дерево папок: все тесты, без папки и папки предметов.
- Добавлены создание, переименование и удаление папок. При удалении папки содержащиеся тесты не удаляются — они возвращаются в раздел «Без папки».
- Добавлено перемещение теста между папками и импорт XLSX в выбранную папку.
- `builtin-tests.json` расширен до схемы version 3: `folders` и `items[].folderId`. Старые файлы версии 2 совместимы и автоматически читаются как библиотека без папок.
- Папки и назначения тестов участвуют в существующей GitHub-синхронизации одним коммитом. При локальном режиме изменение папок вызывает скачивание резервной копии JSON.
- JSON-экспорт сохраняет структуру папок; импорт экспортированного файла восстанавливает папки и назначения тестов.

## Дополнительная полировка

- Добавлено явное пустое состояние поиска, если по введённой строке нет совпадений; карточка «папка пуста» не мешает поисковому результату.
- Обновлён пример структуры `builtin-tests.json` в README до версии 3 с `folders` и `folderId`.
- Версия проекта повышена до 1.4.0.
