# Квиз-арена v1.9.1 — уменьшен верхний отступ на телефонах

- Уменьшен верхний отступ страницы в портретной ориентации на мобильных экранах.
- Для экранов шириной до 440 CSS-пикселей верхний отступ теперь 8 px, для экранов до 760 px — 10 px.
- Отступ автоматически учитывает `safe-area-inset-top`, чтобы не прижимать контент к вырезу/системной области на поддерживаемых устройствах.
- Немного уменьшен нижний отступ у панели языка/темы, чтобы освободить место над основным содержимым.
- Все изменения сделаны поверх существующего адаптивного CSS без правок игровой логики и данных тестов.
