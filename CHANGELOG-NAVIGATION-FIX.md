# Исправление двойной перерисовки при навигации — 1.5.1

## Что исправлено

- Библиотека больше не отображает пустое промежуточное состояние перед появлением загруженных тестов: данные загружаются до переключения экрана.
- Список отчётов и отдельный отчёт открываются одной итоговой перерисовкой после ответа API.
- Добавлен счётчик поколений навигации: запоздавший ответ от предыдущего перехода не может переключить пользователя обратно на устаревший экран.
- Истёкшая авторизация отменяет ожидающие переходы. Выход из кабинета также аннулирует старые запросы.
- Автоматическое открытие отчёта после завершения игры больше не показывает промежуточный экран итогов перед отчётом.

## Проверки

- `node --check server.js` — успешно.
- Синтаксис всех встроенных JavaScript-блоков `public/index.html` — успешно.
- JSON `builtin-tests.json` и `package.json` — успешно разобраны.
- Структурные проверки подтвердили одну перерисовку после загрузки данных в `openLib`, `openReports` и `openReportDetail`.
- Полный браузерный интерактивный тест не выполнялся; Chromium доступен, но в этой сборочной проверке не настроен автоматизированный драйвер кликов.
